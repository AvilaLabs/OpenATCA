# `oa-ieee`

This crate provides explicitly defined IEEE-754 scalar operations used by the deterministic math
and geodesy code. The documented API and operation limits are in the [math and IEEE API proposal](../../docs/core-api/foundations/math-ieee.md).

**Tier: Preview.** The workspace package remains `oa-ieee`; the proposed external package name is
metadata only and is not reserved or published.
