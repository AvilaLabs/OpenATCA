# `oa-nasr`

This crate provides typed parsers for documented FAA NASR CSV subscription files. The selected
subscription/schema cycle is part of the input provenance; no single immutable NASR edition is
implied. See the [NASR API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/formats/nasr.md).

**Tier: Preview.** The proposed external package name in Cargo metadata is not reserved or
published.
