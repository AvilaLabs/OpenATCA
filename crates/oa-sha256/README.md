# `oa-sha256`

This crate implements SHA-256 digest operations for integrity and content identity. A digest does
not authenticate content, establish provenance, or authorize a sender. See the [integrity API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/foundations/integrity.md).

**Tier: Preview.** The proposed external package name in Cargo metadata is not reserved or
published.
