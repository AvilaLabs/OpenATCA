# `oa-arinc424`

This crate parses the documented FAA CIFP subset of ARINC 424-18. It is not a general ARINC 424
parser or encoder. See the [CIFP API proposal](../../docs/core-api/formats/arinc424.md) for
supported record classes and limits.

**Tier: Preview.** The proposed external package name in Cargo metadata is not reserved or
published.
