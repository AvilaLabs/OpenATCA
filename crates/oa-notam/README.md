# `oa-notam`

This crate decodes the documented FAA FNS AIXM 5.1 profile. It does not encode or publish NOTAMs,
provide SWIM transport, or implement general AIXM. See the [NOTAM API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/formats/aixm-notam.md).

**Tier: Preview.** The proposed external package name in Cargo metadata is not reserved or
published.
