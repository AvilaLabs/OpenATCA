# `oa-geo`

This crate provides source-defined WGS-84 inverse/direct geodesics, rhumb operations, sampled
geodesic/rhumb separation and bounded polygon containment. See the [geodesy API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/foundations/geo.md) for units, bounds and limitations.

**Tier: Preview.** Intersections are not implemented; this is not a general geospatial engine.
The proposed external package name in Cargo metadata is not reserved or published.
