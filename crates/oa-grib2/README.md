# `oa-grib2`

This crate decodes the documented GRIB Edition 2 wind-grid subset, including selected NOAA
products and packing representations. It is not a general GRIB2 encoder or decoder. See the
[GRIB2 API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/formats/grib2-winds.md).

**Tier: Preview by template/representation.** The proposed external package name in Cargo metadata
is not reserved or published.
