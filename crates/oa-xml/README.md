# `oa-xml`

This crate parses its documented bounded XML 1.0 subset. It is not a general XML ecosystem or
publisher. See the [text API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/foundations/text.md) for grammar and
error behavior.

**Tier: Preview.** The proposed external package name in Cargo metadata is not reserved or
published.
