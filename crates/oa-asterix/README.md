# `oa-asterix`

This crate contains ASTERIX codec profiles for CAT021, CAT048 and CAT062. CAT034 is not
implemented. Accepted editions, supported items and limitations are listed in the [ASTERIX API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/formats/asterix.md).

**Tier: Preview by category/profile.** The proposed external package name in Cargo metadata is
not reserved or published.
