# `oa-deflate`

This crate implements the documented RFC 1951 DEFLATE and RFC 1952 gzip writing surface. It is
not a general archive extractor. See the [container API proposal](https://github.com/AvilaLabs/OpenATCA/blob/main/docs/core-api/foundations/containers.md) for format bounds and reader/writer separation.

**Tier: Preview.** The proposed external package name in Cargo metadata is not reserved or
published.
