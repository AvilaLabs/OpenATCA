# Core items that let shell code hand behaviour to the core (RULESET B5): a `pub fn` that takes a
# callback (`Fn`, `FnMut`, `FnOnce`, `dyn`, `impl Trait` parameter) or a trait-bound generic, a
# `pub trait` that is not sealed, a generic bounded by a trait that is not a std marker or sealed,
# an unbounded type parameter stored in a `pub` type, and `Fn*`, `dyn` or `fn(..)` anywhere in core
# code, private fns included. Each line is `crate file.rs::name reason`, the file relative to the
# crate's `src/`, the name that of the fn, type, trait or constant that holds it (`impl@Type` for an
# `impl` block). oa-trace fails on an item missing from this list and on an entry nothing matches,
# so the list is reviewed whenever it changes.
#
# OPEN means the type system does not stop a caller from passing a closure that does I/O; the
# callers named were read and each passes a pure key comparison or key hash over its own tables.
oa-replay core/index.rs::index_find OPEN: `eq` is called with a slot number during the probe; callers read: core/table.rs (by_gufi, by_plan, by_tma), core/slots.rs, shell/adsb.rs adsb_slot_of; each compares a key column
oa-replay core/index.rs::index_remove OPEN: `home` is called with a slot number to re-hash it while the probe chain is repaired; callers read: core/table.rs, core/slots.rs, shell/adsb.rs; each hashes a key column
oa-replay core/slots.rs::slots_find OPEN: forwards `eq` to index_find; callers read: shell/tfms.rs, shell/fns.rs; each compares a key column
oa-airspace core/model.rs::at bound is `T: Copy`, a marker with no method: the function only copies an element out of a slice, no behaviour is called through it
