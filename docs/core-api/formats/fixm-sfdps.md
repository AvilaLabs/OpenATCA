# FIXM / SFDPS public API proposal

**Tier:** Preview for decoding; Experimental for encode/publish.

**Current versus proposed surface:** the current package exposes `Limits { drop_window: oa_time_window::DropWindow, .. }`, `Decoder::new(limits)`, and `Decoder::decode(doc, exact_source_bytes, &mut Events)`, along with a separate `prescan` helper. The `oa-sealed` dependency has been removed; callers choose the half-open `DropWindow` value through the companion `oa-time-window` crate. A future stable API review should decide whether this exact companion type is the supported public policy surface.

**Source-backed contract:** FIXM 3.0 core plus FAA NAS 3.0 extension; accepted document root `MessageCollection` in `http://www.faa.aero/nas/3.0`, message type `FlightMessageType`. Message and position timestamps are strict ISO-8601 UTC parsed to Unix milliseconds; position time is distinct from message timestamp and any receive-time supplied by an outer transport. Position is decimal degrees converted to E7, altitude to feet, speed to 0.1 knot, ICAO address to 24-bit integer. Units come from `uom`; unknown units are field errors. The crate also exposes a bounded encoder for its implemented event subset; it is not a publisher or transport.

**Bounds/refusals:** default 50,000 XML elements, 2,048 route bytes, 256 unknown-path entries, 160 bytes per retained unknown path. Whole-document capacity errors are atomic; optional prefix decode records `not_decoded`. Whole-message refusals include missing/bad GUFI, missing/bad timestamp, wrong message type, duplicate flight. Present malformed fields produce error bits and absent values; unknown XML paths are counted, not fatal. Error API should include byte/line positions from `oa-xml` spans for structural errors and field path plus source location for semantic errors; the current public `Reject` list is categorical and does not preserve a source position.

**Encode/publish boundary (J1f):** a bounded encoder emits the implemented event subset with deterministic FIXM/NAS namespaces and ordering; finite-profile tests check emitted structure against pinned official material and round-trip retained fields. This does not establish full SFDPS schema validation, publication, a SWIM envelope, outbound ACK/REJ service, or transport. `oa-fixm` currently depends on `oa-time-window` and `oa-xml`; the internal `oa-sealed` dependency has been removed. Public source-location error policy and the distribution boundary for companion crates remain review items.
